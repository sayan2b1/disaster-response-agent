Data Authenticity Disclosure & Live Provider Downlinks

WHERE DOES THE DATA COME FROM? ARE THE DATAS AUTHENTIC?

Yes, the live telemetry is 100% authentic. When in "Live Open-Meteo Telemetry" mode, the system queries the Open-Meteo API, which aggregates meteorological data directly from the world's primary numerical weather prediction supercomputers:

ECMWF (Europe) Integrated Forecasting System (0.1° high-res grid)
NOAA GFS (USA) Global Forecast System Satellite Mesh
DWD ICON (Germany) Icosahedral Nonhydrostatic Hydro-model

Live vs Stress-Test Simulations: When you select "Severe Cyclone (CRITICAL)" or "Monsoon Drainage (MODERATE)", the simulation purposefully injects extreme scenario thresholds (e.g. 24+ mm rain / 55+ km/h gales) so emergency response teams can simulate evacuations and resource mobilization even if the sky is currently calm.

OPTIONAL FOR OPEN-METEO
How to get reliable API tokens (Free in 60 seconds):
  • OpenWeatherMap: Sign up free at openweathermap.org/api & copy your 32-character key.
  • WeatherAPI.com: Instant sign-up at weatherapi.com to get live Doppler radar telemetry.
  • India Meteorological Department (IMD): Official government data at data.gov.in or Regional Met Center Kolkata.
Keys are stored locally in your browser session / localStorage.
